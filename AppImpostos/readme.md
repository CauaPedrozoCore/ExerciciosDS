> Como Analista Fiscal da aplicação de vendas, eu quero que o sistema
calcule automaticamente diferentes tipos de impostos (ICMS, ISS, IPI) sobre
o valor dos produtos e serviços, para que a nota fiscal seja gerada
corretamente de acordo com a legislação vigente, evitando erros manuais
de cálculo.

> Deve existir uma interface comum para todos os tipos de cálculo de
imposto.

> Considerar: ICMS: 18% sobre o valor; ISS: 5% sobre o valor; IPI: 10% sobre o
valor.
