> Uma academia necessita de um sistema para organizar a matrícula de seus alunos e o
acompanhamento de treinos. O sistema deve ser desenvolvido em Java seguindo os
padrões da POO. Primeiramente, é preciso mapear a relação entre os planos (mensal,
trimestral, anual), os alunos, os instrutores e a matrícula, identificando as classes,
atributos com seus tipos de dados necessários, além dos métodos fundamentais. Faça
uso de construtores, encapsulamento, herança,package etc.

> Objetivo: Implemente o cenário descrito acima onde seja possível a realização da matrícula de
um aluno em um plano específico, sob a supervisão de um instrutor responsável.
